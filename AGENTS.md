o modelo do tcc deve seguir estritamente esse padrao, sem fugir dele e tambem deve utilizar latex

no folder code ficara localizado todo o codigo desenvolvido pelo projeto

o tema do tcc atualmente é: "estudar o comportamento das 
conexões humanas em redes sociais através da teoria dos 
grafos, apoiado por uma arquitetura backend de alta 
performance projetada para ingerir e processar esses dadps 
relacionais em larga escala"

para o desenvolvimento, deverao ser utilizadas fontes 
confiaveis, portanto, voce nao deve se basear nos seus 
dados de treinamento para as fontes. Quando inserir alguma 
referencia ou for pedido por uma referencia sobre x tema, 
voce deve buscar em bibliotecas confiaveis como:
- Portal de Periódicos CAPES
- IEEE Xplore
- SciELO
- Google Scholar

Antes de citar, confira:
- se é artigo científico, livro acadêmico, dissertação ou fonte oficial;
- onde foi publicado;
- quem são os autores;
- ano de publicação — em tecnologia, prefira trabalhos recentes, sem descartar textos clássicos;
- número de citações, quando aplicável;
- presença de DOI;
- relação direta com a afirmação que você está fazendo.

todas as citações devem ser registradas em citations.md

o backend será feito em Hyperf com Swoole
